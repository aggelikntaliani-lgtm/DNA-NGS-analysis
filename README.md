# DNA NGS Variant Calling Analysis (E. coli)
E.coli samples - with recommended ngs pipeline (Linux)
This repository contains the results of a comprehensive Next-Generation Sequencing (NGS) Variant Calling analysis pipeline designed to detect genetic variations (SNPs and INDELs) in Escherichia coli samples.

# Project Overview
The analysis was performed on real raw sequencing data, adhering to the bioinformatics community Best Practices using a Linux environment (Ubuntu/Conda).

# Sample Details
* Sample ID: SRR2584863 (Escherichia coli)
* Reference Genome: ecoli_ref_clean.fasta

# Bioinformatics Pipeline Steps:
1. **Quality Control:** Raw sequencing reads were evaluated using FastQC to assess base quality scores and overall run metrics.
2. **Alignment:** Reads were mapped to the reference genome using BWA, followed by sorting and indexing using Samtools.
3. **Mark Duplicates:** GATK MarkDuplicates was applied to locate and tag duplicate reads resulting from PCR amplification.
4. **Alignment Metrics:** GATK CollectAlignmentSummaryMetrics was used to gather statistical data regarding mapping quality and coverage.
5. **Variant Calling:** GATK HaplotypeCaller was executed to identify raw genomic variations and output them into a standard VCF file.
6. **Variant Filtration:** Hard filtering parameters recommended by GATK were applied separately to SNPs and INDELs to filter out false positives.
7. **Functional Annotation:** Validated variants were functionally annotated using SnpEff (Escherichia_coli_str_k_12_substr_mg1655 database) to determine their impact on genes.


## Repository Contents

* **SRR2584863_output_snps.table**: The final filtered table containing 28 single nucleotide polymorphisms (SNPs), optimized for spreadsheet viewing.
* **SRR2584863_output_indels.table**: The final filtered table containing 13 insertion/deletion mutations (INDELs).
* **snpEff_summary.html**: A comprehensive, interactive HTML report generated by SnpEff displaying charts of variant impacts and genomic distributions.
* **SRR2584863_alignment_metrics.txt**: Summary metrics reporting the percentage and quality of successfully mapped reads.
* **ecoli_ref_clean.fasta**: The bacterial reference genome used during the alignment step.


## Data Utilization
The final output .table files can be downloaded and opened directly in Microsoft Excel (via Data -> From Text/CSV) to inspect genomic positions (POS), reference alleles (REF), alternative alleles (ALT), and variant types.
